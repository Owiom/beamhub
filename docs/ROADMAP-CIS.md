# План развития BeamHub для СНГ-сообщества

Цель: лаунчер, которым пользуются русскоязычные игроки BeamNG.drive каждый день —
без VPN, без платных сервисов, без «недоделанных» кнопок.

## Принципы

1. **Всё работает офлайн.** Каталог, библиотека, сборки и отзывы живут локально;
   облако — только синхронизация, без него ничего не ломается.
2. **Никаких платных API.** Только бесплатные источники и свои алгоритмы.
3. **Честные подписи.** «Заявлено автором» и «проверено BeamHub» — разные вещи.
4. **Каждая кнопка делает то, что написано.** Нет кнопок «на будущее».
