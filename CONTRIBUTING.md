# Как участвовать в BeamHub

Спасибо, что заглянул. Пригодится всё: баг-репорты, идеи, новые источники каталога, код.

## Запуск из исходников

```bat
git clone https://github.com/Owiom/beamhub.git
cd beamhub
py -m pip install -r requirements.txt
py app.py                      :: окно приложения
py app.py --browser            :: веб-интерфейс в браузере
py app.py --no-browser         :: headless, только API
```

Python 3.10+. Для сборки exe нужен PyInstaller, он уже в `requirements.txt`.

## Тесты

```bat
py tests\test_install.py
```

Проверяется установщик: определение типа мода, срез обёртки, дубликаты по хешу,
включение/выключение, удаление и защита от выхода за пределы папки модов.

## Структура

```
app.py                  HTTP-сервер, API, запуск окна
core/
  config.py             поиск игры и папок, settings.json
  db.py                 SQLite: каталог, библиотека, избранное
  http.py               вежливый HTTP-клиент
  installer.py          проверка архива, установка, библиотека
  security.py           токен, Host/Origin, SSRF-проверки
  state.py              события, слежка за загрузками
  tkui.py               интерфейс (tkinter)
  updater.py            обновление через GitHub Releases
  providers/            адаптеры сайтов
web/                    веб-интерфейс
tools/                  сборка иконки и баннера, пакетное обогащение
```

## Новый источник каталога

1. Создай `core/providers/mysite.py`:

```python
SOURCE = "mysite"

def sync(force=False) -> int:
    """Добавить новые моды в базу. Вернуть количество добавленных."""
    ...

def enrich_one(mod: dict) -> dict | None:
    """Дотянуть название, картинку, размер, версию, ссылку на скачивание."""
    ...

def resolve_download(mod: dict) -> str:
    """Что открыть в браузере по кнопке «Установить»."""
    ...
```

2. Зарегистрируй его в `core/providers/__init__.py`:

```python
PROVIDERS = {..., "mysite": mysite}
CATALOG_PROVIDERS = [..., mysite]
SOURCE_LABELS = {..., "mysite": "mysite.com"}
```

3. Проверь руками: `py app.py --no-enrich`, затем кнопка «Обновить каталог».

Требования к провайдеру:

- только публичные страницы, уважай `robots.txt` и лимит частоты (`core/http.py` уже ограничивает);
- никаких обходов Cloudflare и капчи — если сайт отдаёт файл только браузеру, значит скачивание идёт через браузер;
- парсинг на регулярках должен быть терпимым к изменениям вёрстки: лучше пропустить поле, чем упасть.

## Стиль кода

- Python 3.10+, `from __future__ import annotations`, типизация по возможности.
- Без новых зависимостей в рантайме: приложение живёт на стандартной библиотеке, `pillow` нужен только интерфейсу и сборке.
- Тексты интерфейса — по-русски, комментарии — по-русски, имена — по-английски.

## Pull request

1. Одна ветка — одна задача, осмысленное название (`fix/duplicate-badge`, `feat/beamng-provider`).
2. Прогони `py tests\test_install.py` и проверь запуск приложения.
3. Опиши в PR: что меняется, зачем, как проверял. Скриншот для изменений интерфейса.

## Безопасность

Не присылай в PR секреты, токены и чужие персональные данные. Если нашёл уязвимость —
лучше напиши приватно, а не открывай публичный issue с готовым эксплойтом.
