# Обратная связь прямо из приложения

Кнопка **«Отправить»** в окне «Обратная связь» отправляет отчёт без браузера,
почтовой программы и аккаунта GitHub. Чтобы это работало, нужен приёмник —
маленький воркер, который держит секреты у себя, а не в exe.

## Вариант 1. Cloudflare Worker (бесплатно, 5 минут)

1. Создай бота: в Telegram напиши **@BotFather** → `/newbot` → имя и юзернейм →
   он выдаст токен вида `1234567890:AA...`.
2. Напиши своему боту любое сообщение, затем открой
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найди `"chat":{"id":123456789}` —
   это `CHAT_ID`.
3. Зайди на [dash.cloudflare.com](https://dash.cloudflare.com) → **Workers & Pages** →
   **Create** → **Worker** → имя `beamhub-feedback` → **Deploy**.
4. **Edit code** → вставь содержимое [`feedback-worker.js`](feedback-worker.js) → **Deploy**.
5. **Settings → Variables and Secrets** добавь:

   | Имя | Значение |
   |---|---|
   | `BOT_TOKEN` | токен из шага 1 (тип: Secret) |
   | `CHAT_ID` | id из шага 2 |

6. Скопируй адрес воркера вида
   `https://beamhub-feedback.твой-аккаунт.workers.dev`.
7. В BeamHub: **Настройки → «Приёмник обратной связи»** → вставь этот адрес →
   **Сохранить**.

Теперь в окне обратной связи кнопка «Отправить» активна: отчёт уходит в Telegram,
а игроку не нужно ничего открывать.

Хочешь ещё и на почту — добавь в воркер секреты `RESEND_KEY`, `FROM_EMAIL`,
`TO_EMAIL` (ключ бесплатный на [resend.com](https://resend.com), 100 писем в сутки).

## Вариант 2. Formspree / FormSubmit (без своего кода)

Любой сервис, который принимает `POST` с JSON и присылает письмо, подойдёт как есть:
вставь его endpoint в настройку «Приёмник обратной связи». Минус — адрес публичный,
и форма-сервис может ловить спам по своим правилам.

## Что уходит в отчёте

Только то, что видно в превью окна:

- текст «что случилось» и необязательный контакт для ответа;
- версия BeamHub, Windows, сборка, число модов в каталоге и библиотеке;
- путь к игре — **только** если игрок поставил галочку;
- хвост лога — если не снял галочку.

В воркер дополнительно попадает IP из `CF-Connecting-IP` — он нужен, чтобы отличить
спам от честного отчёта. Если не хочешь хранить IP, убери эту строку из `text`.

## Защита от мусора

- honeypot-поле: заполнено — отчёт тихо выбрасывается;
- ограничение длины отчёта (12 000 символов) и размера запроса;
- воркер принимает только `POST`;
- при желании добавь лимит по IP через KV:

```js
const ip = request.headers.get("cf-connecting-ip") || "unknown";
const key = `fb:${ip}:${Math.floor(Date.now() / 60000)}`;
const seen = Number((await env.KV.get(key)) || 0);
if (seen > 5) return json({ error: "rate" }, 429);
await env.KV.put(key, String(seen + 1), { expirationTtl: 120 });
```

## Проверка, что всё работает

1. В приложении: Настройки → «Обратная связь» → напиши «тест» → **Отправить**.
2. Должно появиться «Спасибо, отчёт отправлен», а в Telegram — сообщение.
3. Если воркер ответил ошибкой, текст ошибки покажется в окне (например,
   `telegram 401` — неверный токен, `chat not found` — бот не получал сообщений от тебя).
