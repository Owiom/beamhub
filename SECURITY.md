# Безопасность BeamHub

Приложение локальное: HTTP-сервер слушает `127.0.0.1`, наружу ничего не отдаётся.
Но браузер на той же машине до этого порта дотягивается — отсюда основные риски.

## Модель угроз

| Угроза | Что могло случиться | Как закрыто |
|---|---|---|
| **CSRF** — чужая страница шлёт POST на `localhost` | `fetch('http://127.0.0.1:8787/api/library/remove', …)` удаляет моды, `/api/settings` подменяет папку игры, `/api/quit` гасит приложение | POST требует токен интерфейса (`X-BeamHub-Token`), `Content-Type: application/json` и свой `Origin` |
| **DNS rebinding** — домен атакующего резолвится в `127.0.0.1`, страница читает API как свой | Чтение настроек, путей, установка произвольного zip | Проверка `Host`: принимаются только `127.0.0.1`, `localhost`, `[::1]` с нашим портом |
| **SSRF через `/api/img`** — прокси качает любой URL | Скан локальной сети, чтение локальных сервисов | Резолв имени + запрет приватных/loopback/линк-локальных адресов, проверка каждого редиректа |
| **Подмена файлов при обновлении** | Подложенный архив заменил бы exe | Сверка `sha256` с `digest` из GitHub API, если он есть |
| **Опасные схемы URL** | Мод-ссылка вида `file://…` или `ms-msdt:` запускает локальные обработчики | Открываются только `http(s)` и `mailto` |
| **Path traversal в статике** | `/static/../../secret` | Сравнение через `Path.is_relative_to`, а не по префиксу строки |
| **Zip-slip в моде** | Архив с `../../` пишет вне папки игры | Проверка имён при разборе и перепаковке, проверка распакованных путей после 7-Zip |
| **Удаление вне папки модов** | `remove` по произвольному пути | Путь проверяется через `is_relative_to` для `mods` и `mods_disabled` |
| **Установка из произвольного пути** | `/api/install-file` на любой файл в системе | Разрешены только архивы из папки загрузок |
| **Кликджекинг** | Сайт встраивает наш UI в iframe | `X-Frame-Options: DENY`, `frame-ancestors 'none'` |
| **XSS через данные сайтов** | Названия/описания модов попадают в HTML | В веб-интерфейсе всё экранируется (`esc`), CSP запрещает сторонние скрипты |

## Что осознанно не закрыто

- **Нет подписи exe.** SmartScreen будет ругаться: подпись кода платная. Обновление проверяет
  `sha256`, если GitHub его отдаёт, но полноценной цепочки доверия нет.
- **Моды — произвольный код.** BeamNG исполняет Lua из модов; установка мода из интернета
  ничем не отличается от запуска скачанного exe. Приложение проверяет структуру архива,
  но не содержимое.
- **Локальный злоумышленник** с правами вашего пользователя всё равно прочитает файлы
  и токен из памяти процесса — от этого защититься нельзя, это не сетевой риск.

## Как проверить

```bat
:: Host не локальный -> 403
curl -s -o NUL -w "%{http_code}" -H "Host: evil.com" http://127.0.0.1:8787/api/state

:: POST без токена -> 403
curl -s -o NUL -w "%{http_code}" -X POST -H "Content-Type: application/json" ^
     -d "{}" http://127.0.0.1:8787/api/library/rescan

:: SSRF -> 4xx/5xx, картинка не отдаётся
curl -s -o NUL -w "%{http_code}" "http://127.0.0.1:8787/api/img?u=http%3A%2F%2F127.0.0.1%3A8787%2Fapi%2Fping"
```
